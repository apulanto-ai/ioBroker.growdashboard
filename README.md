# ioBroker.growdashboard

Grow computer adapter for plants. Monitors and visualizes sensor data (temperature, humidity, CO2, VPD, light, EC, pH) from ioBroker objects and Grafana dashboards.

## Features (planned)

- Multi-room grow environment monitoring
- VPD, DLI and other grow parameter calculations
- Grafana dashboard integration
- ioBroker state visualization
- Configurable alerts and thresholds

## Configuration

Configure your grow rooms and sensor state IDs in the adapter settings. Optionally connect a Grafana instance for extended visualization.
